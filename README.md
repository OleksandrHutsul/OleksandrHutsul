## 👨‍💻 About me

I'm a software developer working mostly with C# and the .NET ecosystem.

A lot of my work lives somewhere between APIs, databases, integrations and web applications. I enjoy getting past the immediate bug and understanding what is actually happening across the whole flow.

Backend development is the part I enjoy most, although I regularly work across the full stack with Blazor and have also built desktop and cross platform applications.

These days I'm also exploring AI and how it can solve actual software problems rather than adding an AI button to something and hoping for the best.

## 🧠 How I like to build things

~~~text
Readable > clever
Simple > unnecessarily complicated
Understand the problem > patch the symptom
~~~

I like code that another developer can open six months later without needing an archaeological expedition to understand it.

Refactoring is good. Deleting unnecessary code is sometimes even better.

And every once in a while, the fastest debugging strategy is checking Git blame.
